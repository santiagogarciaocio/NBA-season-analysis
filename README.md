# NBA-season-analysis
We explored kaggle's [NBA player's database](https://www.kaggle.com/datasets/justinas/nba-players-data/data). 

Through EDA we found the average NBA player. We explored the growth of overseas players in the NBA as well as the differences between overseas and USA based players in their average stats. 

Following the information gleaned from the EDA, as well as knowledge about basketball, we realize the importance that individual players, the so-called superstars/franchise player/etc, could make on a game of basketball.  

With that in mind we created a tree classification model to determine if a player could be considered a superstar or not. 

Following that we finished with a K-means clustering of the team to see if we could subset the historically successful teams.
